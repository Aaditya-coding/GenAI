# 🤖 GenAI & LangChain

A hands-on repository for learning and building applications with **Generative AI, LangChain, LLMs, RAG, Retrieval, Tools, Agents, and Prompt Engineering**.

This repository contains my experiments, implementations, notes, and projects while exploring the modern Generative AI ecosystem with Python.

---

## 🚀 What You'll Find Here

The repository is organized around different components of the LangChain ecosystem:

- 🔗 LangChain Chains
- 🤖 LangChain Agents
- 🧠 LLM & Chat Models
- 📄 Document Loaders
- 🔎 Retrievers
- 🛠️ Tools & Tool Calling
- 🔄 Runnables & LCEL
- 📦 Output Parsers
- 🧩 Structured Output
- 💬 Prompt Engineering
- 🗃️ Vector Stores
- 🔍 RAG Applications
- 🧪 GenAI Experiments
- 🚀 GenAI Projects
